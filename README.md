# C Programming End-Sem Exam Guide — Units I–III

Static website built from the syllabus screenshot and the three uploaded C programming question papers (2023, 2024, and 2024–25/2025 paper).

## Files
- `index.html`
- `styles.css`
- `app.js`
- `vercel.json`

## Run locally
Open `index.html` in a browser. No build step or backend is required.

## Deploy on Vercel
1. Upload these files to the existing GitHub repository (replace the previous site's files if this is the intended replacement).
2. Commit and push.
3. Vercel should redeploy automatically because the repository is already connected.
4. Use the Vercel deployment URL to check the live version.

## Scope
The guide focuses on Units I, II and III as shown in the supplied syllabus screenshot. Questions that belong only to Unit IV are intentionally not included. Some paper questions span syllabus topics; those are placed under the closest relevant topic. Answers are study-ready summaries and programs, not a claim that every ambiguous OCR detail in a scanned paper is certain.
